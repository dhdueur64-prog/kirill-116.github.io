# WorkTools — агрегатор инструментов для работы

Клиентский сайт-каталог автономных веб-приложений для повседневной работы.

## Принципы

- **Только браузер** — вся обработка на стороне пользователя
- **Без серверов** — данные не уходят никуда
- **Без регистрации** — открыл и пользуешься
- **Офлайн** — после первой загрузки большинство инструментов работают без сети
- **Без аналитики** — нет сбора статистики использования

## Обратная связь

Кнопка **💬** на главной — форма (ошибка / идея / улучшение).

Чтобы получать сообщения на почту, в `js/config.js` укажите:

```js
endpoint: 'https://formspree.io/f/ВАШ_ID',  // formspree.io
feedbackEmail: 'you@example.com',           // запасной mailto
```

│   ├── transpose/
│   ├── wordcount/

└── README.md

## Как добавлять новый инструмент

1. Создайте папку в `tools/`, например `tools/pomodoro/`
2. Внутри — самостоятельный `index.html` + свои стили/скрипты
3. Добавьте карточку в `index.html` и пункт в форму обратной связи
4. Инструмент должен работать **полностью на клиенте**

## Запуск локально

```bash
npx serve .
# или
python -m http.server 8080
```

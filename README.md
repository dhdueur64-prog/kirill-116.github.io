# WorkTools — агрегатор инструментов для работы

Клиентский сайт-каталог автономных веб-приложений для повседневной работы.

## Принципы

- **Только браузер** — вся обработка на стороне пользователя
- **Без серверов** — данные не уходят никуда
- **Без регистрации** — открыл и пользуешься
- **Офлайн** — после первой загрузки большинство инструментов работают без сети

## Как добавлять новый инструмент

1. Создайте папку в `tools/`, например `tools/pomodoro/`
2. Внутри — самостоятельный `index.html` + свои стили/скрипты
3. Добавьте ссылку на карточку инструмента в `index.html` (замените «Скоро» на кнопку «Открыть»)
4. Инструмент должен работать **полностью на клиенте** (localStorage, File API, Web Crypto и т.д.)

## Запуск локально

Просто откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
npx serve .
# или
python -m http.server 8080
```

## Категории инструментов

1. **Планирование и учёт времени** — смены, отпуска, помодоро, часовые пояса, рабочие дни
2. **Работа с текстом и данными** — diff, очистка, экстракция, рыбный текст
3. **Таблицы и файлы** — merge, конвертеры, анонимизация, SQL-генератор
4. **Безопасность и доступы** — пароли, хеши, Base64/JWT, утечки
5. **Коммуникация и рутина** — шаблоны, валюты, подписи, чек-листы, QR
6. **ЖКХ и управление МКД** — проведение ОСС, подсчёт бюллетеней, протоколы

### Готовые инструменты

| Инструмент | Путь | Описание |
|------------|------|----------|
| Авто ОСС | `tools/oss/index.html` | Проведение Общего собрания собственников и подсчёт бюллетеней |
| Калькулятор рабочих смен | `tools/shifts/index.html` | Циклические графики, сотрудники, календарь, отпуска, печать |
| Генератор графика отпусков | `tools/vacations/index.html` | Сотрудники, периоды отпусков, календарь на год, праздники, печать |
| Умное сравнение текстов | `tools/diff/index.html` | Diff двух текстов, подсветка, навигация, выбор фрагментов, авто-объединение |
| Соединение таблиц | `tools/join/index.html` | Merge/Join двух таблиц по столбцам (Inner, Left, Right, Full), несколько ключей |
| Поиск дублей строк | `tools/duplicates/index.html` | Поиск повторяющихся строк, группы дублей, выгрузка уникальных / только дублей |
| Генератор тестовых таблиц | `tools/tablegen/index.html` | Случайные данные по колонкам и словарям, экспорт CSV/TSV |
| Транспонировщик таблиц | `tools/transpose/index.html` | Быстрая замена строк и столбцов местами (из Excel/Sheets) |

---

Все инструменты выполняются только на стороне пользователя.

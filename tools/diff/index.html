Итоговый объединённый текст

Объединить автоматически: проходит по отличиям и сохраняет содержимое обоих текстов. Совпадающие строки — один раз; строки только из А или только из Б — включаются; изменённые строки — берутся обе (сначала А, затем Б), чтобы ничего не потерялось.

Все данные обрабатываются только в вашем браузере. Ничего не отправляется на сервер.

2. Настройки соединения

Зачем соединять таблицы?

У вас есть две таблицы с общими данными (например, сотрудники и отделы, заказы и клиенты). Соединение «склеивает» строки по совпадающим значениям в выбранных столбцах — без Excel, без VLOOKUP и без формул.

Ключ соединения — столбец (или несколько), по которому ищем совпадения. Можно выбрать несколько пар столбцов: тогда строка попадёт в результат только если совпадут все пары.

Внутреннее (Inner) Только строки, у которых нашлось совпадение в обеих таблицах. Всё, что не нашлось — отбрасывается.
Оставляет: пересечение A ∩ B
A: 1,2,3 · B: 2,3,4 → результат: 2,3
Левое (Left) Все строки из таблицы A. Если в B нашлось совпадение — подтягиваем данные из B. Если нет — ячейки из B будут пустыми.
Оставляет: все из A + совпадения из B
A: 1,2,3 · B: 2,3,4 → результат: 1,2,3
Правое (Right) Все строки из таблицы B. Данные из A подтягиваются при совпадении, иначе ячейки из A пустые.
Оставляет: все из B + совпадения из A
A: 1,2,3 · B: 2,3,4 → результат: 2,3,4
Полное (Full Outer) Все строки из A и все строки из B. Где совпало — склеиваем, где нет — оставляем с пустыми ячейками с другой стороны.
Оставляет: объединение A ∪ B
A: 1,2,3 · B: 2,3,4 → результат: 1,2,3,4

Нажмите «Тестовый пример» в шапке — подставятся таблицы сотрудников и отделов, ключ уже выбран. Попробуйте переключить тип соединения и нажмите «Соединить».
